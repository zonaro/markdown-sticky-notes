Documentation

Where are notes stored?

Each direct .md or .markdown file inside ~/notes/ becomes a desktop sticky note. Subdirectories are not monitored.

How does deletion work?

Deleting a sticky note permanently deletes its corresponding file, and deleting a file removes its sticky note. There is no extension trash. Back up the folder if you need recovery.

How do I pin a note?

Right-click the note and choose “Pin above windows”; choose the inverse option to unpin it.

Can I use other Markdown editors?

Yes. The body remains plain UTF-8 Markdown, while extension-specific frontmatter stores positioning, size, color, and pin state.
